# AP Computer Science: A
This course explores Computer Science through the lens of the Java platform, with an emphasis on learning the Java Programming Language. No prior programming experience is required; students leave the course with a solid handle on programming with statically-typed languages. This course is intended to fulfill an undegraduate CS101 requirement at the high school level, utilizing an entire school year instead of a single semester.

The recommended course textbook is "Introduction to Java Programming," by Y. Daniel Liang (10th Edition or later). 

The labs emphasize hands-on experiences -- students use an Integrated Development Environment (IDE) and Git in order to complete the work. While any lightweight IDE can be utilized, the recommended IDE is VSCode. Students begin the course by installing the IDE and creating a GitHub account.

The early labs are graded for tests and correctness automatically using a GitHub Actions Workflow. The later labs ask students to fork template repositories, while the final lab tasks students to create the project entirely on their own.

Beyond gaining Java experience, the course exposes students to:
    - Linux environments.
    - Using Git and Version Control Systems.
